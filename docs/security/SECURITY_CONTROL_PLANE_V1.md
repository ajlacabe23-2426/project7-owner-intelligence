# Project 7 Security Control Plane v1

Updated: 2026-10-02

This repository-level defensive layer adds reachable-history credential scanning, immutable GitHub Action pinning, explicit read-only workflow permissions, checkout credential removal, tracked secret-like file rejection, Dependabot coverage for Python and GitHub Actions, scheduled dependency auditing, and incident-response guidance.

It does not make Project 7 production-ready. Authentication, tenant isolation, managed persistence, data-provider trust, privacy/retention operations, network abuse protection, and independent security review remain separate production requirements.
